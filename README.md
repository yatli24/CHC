# UCSB Climate Hazards Center Research Capstone

## Project Description
Assessing the predictive skill of General Circulation Models (GCMs) in various regions of interest

## Repository Guide
- .devcontainer - Development container for the project (Dependency version control)
- scripts - Folder containing scripts used to reproduce our analyses and findings
  - preprocessing - Contains data preprocessing functions for raw NetCDF climate model data

- figures - Folder containing graphs and plots
  - Corr_heatmap - Heatmaps by climate model and region of interest, showing correlation between predicted and actual precipitation for each lead time and month.
